# Trunk-based development forces continuous integration

Committing directly to the `trunk` branch forces developers to integrate their changes daily, completely eliminating massive, system-breaking merge conflicts. It respects the reality that [[Code is read far more often than it is written]].[^1]

[^1]: Forsgren, N., et al. (2018). Accelerate. IT Revolution Press.
