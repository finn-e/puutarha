# Retrieval-augmented generation grounds AI in facts

RAG pipelines inject verified external data into the prompt before the model generates a response, drastically reducing hallucinations. It functions as an external memory bank because [[Cognitive offloading frees up mental RAM]].

[^1]: Lewis, P., et al. (2020). Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks. NeurIPS.
