# Z-axis layer lines act as structural weak points in FDM printing

Because FDM printing stacks discrete 2D layers, the resulting 3D object is highly susceptible to shearing along the Z-axis. Engineers must orient parts so that load-bearing forces run perpendicular to the layer lines.[^1]
