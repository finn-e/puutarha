# Grafana provides a unified visualization layer for disparate data sources

Grafana queries Prometheus for metrics, Loki for logs, and Tempo for traces, combining them into a single, cohesive dashboard. This 'single pane of glass' prevents alert fatigue and ensures [[Observability is more than just logging]].[^1]

[^1]: Grafana Documentation: Dashboards.
