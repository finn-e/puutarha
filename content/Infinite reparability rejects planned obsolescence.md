# Infinite reparability rejects planned obsolescence

Because the Svalboard uses standard 3D printed components, open-source firmware, and hot-swappable switches, a user can repair or replace any failing part indefinitely. This aligns perfectly with the right-to-repair ethos.[^1]

[^1]: Wiens, K. (2020). The Right to Repair movement principles.
