# Slicing parameters dictate physical object properties

Perimeter walls, infill density, and bridging logic generated by the slicer software directly control the weight, strength, and print time of the hardware. This bridging of code and reality mimics how software architecture works.[^1]

[^1]: Slic3r / PrusaSlicer Documentation.
