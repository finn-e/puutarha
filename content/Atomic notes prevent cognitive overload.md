# Atomic notes prevent cognitive overload

Restricting a note to a single, distinct concept ensures it remains modular and easily digestible. Because [[Working memory is severely limited]], atomicity acts as a mental buffer, similar to how [[Ergonomic hardware reduces physical cognitive load]].[^1]

[^1]: Miller, G. A. (1956). The magical number seven.
