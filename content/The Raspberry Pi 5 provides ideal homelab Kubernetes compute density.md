# The Raspberry Pi 5 provides ideal homelab Kubernetes compute density

With the BCM2712 quad-core processor and 8GB of RAM, the Raspberry Pi 5 offers a massive leap in bare-metal performance for home clusters. Stacking these boards creates a highly capable edge environment, demonstrating how [[Homelab Kubernetes mirrors enterprise production environments]].[^1]

[^1]: Raspberry Pi Foundation. Pi 5 Hardware Specifications.
