# Games are sophisticated interactive state machines

Beneath the art and music, every video game is simply a massive loop checking for player inputs and updating internal variables 60 times a second. Understanding this logical foundation is similar to how [[QMK allows complex state machines in firmware]].[^1]

[^1]: Nystrom, R. (2014). Game Programming Patterns. Genever Benning.
