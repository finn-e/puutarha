# Auto popping PS4 trophies on PS5 alters the statistical value of Platinums

When a developer allows a player to import a PS4 save file and instantly unlock the corresponding PS5 Platinum, it artificially inflates trophy counts without requiring new mechanical effort. This demonstrates how [[Local optimization often leads to global sub-optimization]] in leaderboards.[^1]

[^1]: PSNProfiles Leaderboard Rule Adjustments.
