# QMK allows complex state machines in firmware

With QMK, a keyboard transcends being a simple input device, utilizing tap-dances, mod-taps, and deep layer logic to process commands internally. Programming this logic ensures [[Immutability reduces unexpected side effects]] across different OS environments.[^1]

[^1]: QMK Contributors. (2024). Quantum Mechanical Keyboard Firmware Docs.
