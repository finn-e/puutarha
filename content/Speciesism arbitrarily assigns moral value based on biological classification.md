# Speciesism arbitrarily assigns moral value based on biological classification

Discriminating against a pig while protecting a dog relies on arbitrary species boundaries rather than the shared capacity to suffer. This logical fallacy must be dismantled through rational ethics and consistent compassion.[^1]

[^1]: Singer, P. (1975). Animal Liberation.
