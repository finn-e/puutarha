# System transparency empowers user agency

If you do not have root access and the ability to read the source code of your machine, you are merely a tenant, not an owner. Seizing control of the underlying system is how you dictate that [[Default settings dictate user behavior]].[^1]

[^1]: Stallman, R. (1985). The GNU Manifesto. Dr. Dobb's Journal.
