# Rolling releases provide continuous access to upstream software

Operating systems like Arch Linux deliver software updates the moment they are compiled by the developers, completely eliminating the massive paradigm shifts of major OS version upgrades. It is the desktop equivalent to how [[Trunk-based development forces continuous integration]].[^1]

[^1]: Arch Linux Wiki. (2024). The Arch Way.
