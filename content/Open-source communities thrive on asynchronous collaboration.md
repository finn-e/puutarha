# Open-source communities thrive on asynchronous collaboration

Building a massive kernel across thousands of timezones is impossible via synchronous meetings; it demands mailing lists, pull requests, and immaculate documentation. This globally distributed success proves [[Asynchronous communication respects makers schedules]].[^1]

[^1]: Raymond, E. S. (1999). The Cathedral and the Bazaar. O'Reilly Media.
