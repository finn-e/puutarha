# Custom firmware layers act as physical macros for software

Instead of relying on OS-level software shortcuts, baking layers into firmware via ZMK ensures that your macros travel with the hardware. The keyboard behaves identically across Linux, Windows, and Mac.[^1]

[^1]: QMK/ZMK Layer Logic Architecture.
