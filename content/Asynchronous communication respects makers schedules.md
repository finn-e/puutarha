# Asynchronous communication respects makers schedules

Forcing immediate responses via chat apps shatters the uninterrupted blocks of time engineers need to build systems. This is why [[Open-source communities thrive on asynchronous collaboration]].[^1]

[^1]: Graham, P. (2009). Maker's Schedule, Manager's Schedule.
