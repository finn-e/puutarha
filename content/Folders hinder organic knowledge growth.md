# Folders hinder organic knowledge growth

Hierarchical folder structures force ideas into mutually exclusive categories before the concept has fully matured. This rigid taxonomy contradicts how human associative memory works; instead, [[Tags provide multiple pathways to the same idea]].[^1]

[^1]: Weinberger, D. (2007). Everything Is Miscellaneous.
