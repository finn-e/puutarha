# eBPF provides kernel-level networking performance

Extended Berkeley Packet Filter allows sandboxed programs to run directly in the Linux kernel space without changing kernel source code. This eliminates user-space context switching, drastically speeding up networking and observability.[^1]

[^1]: eBPF.io. Introduction to eBPF.
