# Package managers resolve dependency hell

By centralizing the logic of what libraries a piece of software needs to run, systems like `pacman` prevent conflicting libraries from corrupting the entire file system. Resolving these deep webs prevents how [[Local optimization often leads to global sub-optimization]].
